Voltage to Temperature Transfer Function

The LM35 produces an output voltage that is linearly proportional to the Celsius temperature at a rate of exactly 10 mV/°C (0.010 V/°C).

V_out (Volts) = (ADC_Count / 4095) * V_ref
Temp (°C) = (V_out * 1000 mV / 10 mV/°C) + Offset

For example, 250 mV corresponds directly to 25.0 °C. The ESP32 ADC reads this analog voltage on an assigned ADC pin (e.g., GPIO 34 / 35 / 36 / 39).

ESP32 ADC Linearity Note: The ESP32 built-in SAR ADC is notoriously non-linear below ~100 mV and near ~3.1 V (at 11 dB attenuation). Temperatures below 10 °C produce voltages near the dead zone (<100 mV). Applying ADC curve calibration in Arduino code or using multi-sample averaging improves accuracy.

Voltage Divider & Relative Percentage Calibration

The LDR resistance decreases exponentially as ambient photon flux increases. In a voltage divider circuit with a fixed resistor (R_fixed, typically 10 kΩ):

V_out = V_in * [ R_fixed / (R_ldr + R_fixed) ]
Light (%) = Clamp(0, 100, (Dark_ADC - Raw_ADC) / (Dark_ADC - Bright_ADC) * 100)

Configurable reference readings (Dark = 3800, Bright = 350) scale the output into an intuitive 0% to 100% relative brightness indicator.

Scientific Rigor: Why Not Lux? Standard CdS photoresistors have non-linear logarithmic resistance curves and vary significantly by manufacturing batch and ambient temperature. Reporting calibrated relative brightness (%) is technically honest; calculating true Lux without an optical lux-meter calibration curve is misleading.

Integration Architecture Overview

This website is architected for non-invasive integration with your ESP32 Arduino sketch:

  • Autonomous Device: The ESP32 retains 100% control over the servo motors. The website does NOT send motor commands.
  • Decoupled Telemetry: If the website is closed or internet drops, the ESP32 keeps operating its sensor and servo loop locally.
  • Realtime Database: Readings are published by the ESP32 over HTTPS / WebSocket to Firebase Realtime Database.

Refer to HARDWARE_INTEGRATION.md in the project directory for the exact non-blocking Arduino code template.
